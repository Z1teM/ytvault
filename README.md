# YTVault

Локальная база видео YouTube: превью, длительность, просмотры, каналы. Работает на своём компьютере,
без аккаунтов и API-ключей — сервер сам забирает данные со страниц YouTube.

![Node.js](https://img.shields.io/badge/Node.js-%E2%89%A518-3c873a) ![Express](https://img.shields.io/badge/Express-5-000000)

## Быстрый старт

1. Скачай папку проекта (или `git clone`).
2. Запусти **`start.bat`**.

Скрипт сам:
- скачивает portable Node.js 26.13.0 в папку `runtime/` (около 40 МБ, один раз);
- ставит зависимости (`npm install`), если папки `node_modules/` ещё нет;
- запускает сервер и открывает http://localhost:3000.

Чтобы остановить сервер — закрой окно консоли. Интернет нужен только для скачивания Node.js,
установки зависимостей и обновления данных о видео.

## Запуск вручную

```bash
npm install
npm start          # то же, что node server.js
```

Сервер слушает порт **3000**. Если он занят — поменяй число в конце `server.js`.

## Где хранятся данные

| Файл / папка | Что это |
|---|---|
| `videos.json` | вся коллекция: id, название, канал, длительность, просмотры, дата добавления |
| `thumbs/` | скачанные превью видео (`<videoId>.jpg`) |

Оба места живут рядом с кодом и не зависят от браузера. Чтобы перенести коллекцию на другое
устройство, достаточно скопировать `videos.json` и `thumbs/`.

## API

| Метод | Путь | Назначение |
|---|---|---|
| GET | `/api/videos` | вся коллекция |
| POST | `/api/videos` | сохранить коллекцию целиком (JSON в теле) |
| GET | `/api/ytinfo?id=...` | просмотры и длительность одного видео |
| GET | `/api/thumb?id=...` | скачать превью одного видео |
| POST | `/api/thumbs-all` | докачать все недостающие превью |
| POST | `/api/sync-all` | обновить просмотры и длительность у всей коллекции |
| GET | `/thumbs/<id>.jpg` | сохранённое превью |

## Структура

```
YTVault/
├─ index.html          интерфейс (один файл, Tailwind с CDN)
├─ server.js           Express: статика + API + парсинг YouTube
├─ videos.json         коллекция видео (JSON)
├─ thumbs/             превью видео
├─ logo.png            логотип и favicon
├─ package.json
├─ start.bat           запуск с автоустановкой Node.js
└─ runtime/            скачанный Node.js (не коммитится)
```

В этом репозитории `videos.json` пустой, а `thumbs/` — пустая папка: свою коллекцию
добавляешь через интерфейс, файлы появятся сами.

## Особенности

- **Обход DNS.** Системный резолвер на машине разработчика не видел `www.youtube.com` и
  `i.ytimg.com`, поэтому `server.js` спрашивает IP напрямую у DNS Google (`8.8.8.8`) и ходит
  на него с подменой `Host`. Если у тебя обычный DNS — этот код просто работает как обычно.
- **Просмотры и длительность** вытаскиваются из `ytInitialPlayerResponse` на странице видео,
  регэкспом не парсится из-за вложенных строк — используется подсчёт скобок.
- **Превью** скачиваются на диск, чтобы не дёргать YouTube при каждой загрузке страницы.
  Серые заглушки YouTube (меньше 1 КБ) отбрасываются.
- **Паузы между запросами** (100–150 мс) в пакетных операциях, чтобы YouTube не ограничивал доступ.
- Сервер слушает только локальную машину и не предназначен для публикации в интернете.

## Ограничения

- GitHub Pages не подойдёт: нужен Node.js, статикой здесь не обойтись.
- Для запуска на новом устройстве нужен интернет (скачать Node.js и зависимости).
- Данные YouTube могут перестать парситься, если Google поменяет разметку — тогда правится
  `fetchYTInfo` в `server.js`.
